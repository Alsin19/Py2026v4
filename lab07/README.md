## Задание 7

### functions.py
Библиотека функций без input()/print().

- sum_digits(number) — сумма цифр модуля; для 0 → 0; abs() берётся до цикла,
  чтобы отрицательное число не «застряло» при // 10.
- average(numbers) — среднее или None для пустого списка; список не меняется.
- normalize_text(text) — нижний регистр, обрезка краёв, один пробел между
  словами (правила задания №5).
- select_numbers(numbers, threshold) — новый список чисел не меньше порога,
  порядок и повторы сохраняются.

### main.py
Запрашивает целое число, строку чисел, произвольный текст и порог;
демонстрирует все функции. Для пустого списка вместо среднего печатает
«Нет данных».

### Проверки

sum_digits:
- обычные: 123 → 6, 999 → 27;
- граничные: 0 → 0, 7 → 7, 10 → 1, 1000 → 1;
- особые: -456 → 15, -5 → 5, -1000 → 1, -98765 → 35 (abs до цикла).

average:
- [] → None (main печатает «Нет данных»);
- [5] → 5.0; [1,2,3] → 2.0; [-5,0,2,5] → 0.5; [1,2] → 1.5;
- [0,0,0] → 0.0; исходный список не изменяется.

normalize_text:
- "  Hello   World  " → "hello world";
- "Привет,   Мир!" → "привет, мир!";
- "     " → ""; "" → ""; "One" → "one"; "a\tb\nc" → "a b c".

select_numbers (не меньше порога):
- контроль: [-5,0,2,5], порог 2 → [2, 5];
- непустой пример: [-3,-1,4,1,4], порог 1 → [4, 1, 4];
- пустая выборка: [-5,0,2,5], порог 10 → [];
- пустой список: [], порог 2 → [];
- повторы: [5,5,5], порог 5 → [5,5,5] (граница включена);
- все меньше порога: [-1,-2], порог 0 → [].

Контрольный список из условия: [-5, 0, 2, 5], порог 2 → [2, 5].
