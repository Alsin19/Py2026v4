## Задание 5

### normalize.py
Обрезает пробельные символы по краям и заменяет внутренние серии
пробельных символов одним пробелом. Регистр и пунктуация сохраняются.
Выводит исходную/новую длину, нормализованный текст и число слов.

Проверки:
- обычная: "  Hello   World  " → "Hello World", слов 2, длины 16 → 11;
- только пробелы: "     " → "", слов 0, длины 5 → 0;
- пустая строка → длины 0/0, слов 0;
- без лишних пробелов: "Hello" → "Hello", длины 5/5, слов 1;
- табуляция и переводы строк: "a\tb\nc" → "a b c", слов 3;
- пунктуация сохраняется: "  Привет,   мир!  " → "Привет, мир!", слов 2.

### palindrome.py
Проверка палиндрома: игнорируются регистр и обычные пробелы;
остальные символы (включая пунктуацию) сравниваются как есть.
Пустая после очистки строка → "Нет текста". Используется срез [::-1]
(альтернатива циклом — по половине длины очищенной строки).

Проверки:
- "А роза упала на лапу Азора" → Палиндром;
- "Anna" → Палиндром;
- "Привет" → Не палиндром;
- "", "   " → Нет текста;
- "А, роза" → Не палиндром (запятая);
- "шалаш", "abba", "я" → Палиндром.

### replace.py
Заменяет все двоеточия на дефисы и выводит число замен и новую строку.
Сначала считаем count(":"), затем replace(":", "-").

Проверки:
- "a:b:c" → замен 2, "a-b-c";
- "abc" → 0, "abc";
- ":::" → 3, "---";
- "" → 0, "";
- "Время: 10:30" → 2, "Время- 10-30";
- "a::b:c" → 3, "a--b-c".

### variant.py (начинается с «к»)
Разбивает по пробельным символам, чистит края strip(".,!?;:"),
приводит к нижнему регистру, пропускает пустые, отбирает слова,
начинающиеся с "к". Повторы сохраняются; если совпадений нет —
"Нет совпадений" и "Количество: 0".

Контрольный текст: "Анна, армия! Я читаю. Книга, край, рама."
→ книга, край; Количество: 2.

Проверки:
- нет подходящих: "Анна, армия!" → Нет совпадений, 0;
- пустая строка / только пробелы → Нет совпадений, 0;
- только пунктуация "..., ;;;" → Нет совпадений, 0;
- повторы "кот, Кот! кот?" → кот ×3, количество 3;
- слово "к": "к, к." → к ×2, количество 2;
- смешанный регистр "Книга, КРАЙ" → книга, край, 2;
- внутренняя пунктуация "ко:т" → strip не трогает внутреннее
  двоеточие; слово начинается с "к" → подходит.
