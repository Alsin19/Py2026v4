# Проект: План тренировок (консольная программа)

Локальная консольная программа на Python без сторонних библиотек.
Объединяет условия, циклы, коллекции, функции, проверку данных и JSON.

Вариант: план тренировок; `amount` — продолжительность в минутах;
`completed` — тренировка завершена.

## Структура
project/
main.py # меню, ввод, сообщения
logic.py # проверка, добавление, поиск, статус, удаление, статистика
storage.py # чтение/запись JSON
test_logic.py # тесты logic.py
test_storage.py # тесты storage.py
data.json # данные
README.md


## Требования

- Python 3.8+.
- Сторонние библиотеки не нужны.
- Интернет не нужен.

python main.py
