## Задание 10

### main.py
- read_positive_integer() — повторяет ввод, пока не получено целое > 0;
  разные сообщения для «не целое число» и «должно быть больше нуля».
  Проверка последовательности abc, 0, -2, 3: три сообщения об ошибке,
  затем возврат 3.
- main() — читает matrix.txt через read_matrix, считает суммы строк и
  столбцов, сумму нечётных элементов (вариант), формирует отчёт в памяти
  и только после успешной проверки записывает report.txt.
- Обрабатываются FileNotFoundError, UnicodeDecodeError, PermissionError,
  общий OSError и ValueError формата.
- При любой ошибке чтения/проверки main() выходит до открытия
  report.txt на запись — существующий отчёт остаётся без изменений.
- Входной файл открывается только на чтение (в files_lab.read_matrix).

### files_lab.py
read_matrix(path) — строгое чтение матрицы:
- первая строка: два положительных целых rows cols;
- далее ровно rows строк, в каждой ровно cols целых;
- пустые и лишние строки — ошибка (ValueError с номером строки);
- один обычный перевод строки после последних данных допустим.

Проверки:
- корректный matrix.txt → [[1, -2, 3], [4, 0, -6]];
- пустой файл → ValueError «Файл пуст: отсутствует заголовок»;
- неверный заголовок (одно число, нечисловые части, неположительные
  rows/cols) → ValueError с указанием строки 1;
- нечисловая ячейка (например, "1 x 3") → ValueError со строкой и токеном;
- неправильное количество столбцов в строке → ValueError с номером строки;
- пустая строка внутри данных → ValueError с номером строки;
- недостаточно строк данных / лишние строки → ValueError с ожидаемым
  и фактическим количеством.

### Сценарии ошибок
- matrix.txt отсутствует → сообщение «файл не найден», report.txt
  не трогается;
- в файле неверный UTF-8 → сообщение о кодировке, report.txt не трогается;
- нет прав на чтение → сообщение о доступе, report.txt не трогается;
- неверный формат → сообщение с номером строки, report.txt не трогается;
- нет прав на запись report.txt → сообщение, исходный report.txt
  остаётся прежним (открытие на запись не удалось).
