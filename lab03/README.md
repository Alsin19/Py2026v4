## Задание 3

### minimum.py
Минимум из трёх целых чисел через ветвление (без min/max/sort).

Проверки:
- обычные: 3,7,5 → 3; 9,2,8 → 2; 4,6,1 → 1;
- равные: 5,5,5 → 5; 2,2,7 → 2; 6,3,3 → 3;
- отрицательные: -4,-1,-9 → -9;
- смешанные: -2,0,5 → -2.

### calculator.py
Калькулятор с одной операцией +, -, *, /; результат с двумя знаками.
Без eval().

Проверки:
- обычные: 5+3 → 8.00; 5-3 → 2.00; 5*3 → 15.00; 5/2 → 2.50;
- дробные: 0.1+0.2 → 0.30;
- деление на ноль: 7/0 → «Деление на ноль запрещено»;
- неизвестная операция: %, ^, пустая строка → «Неизвестная операция»;
- отрицательные: -4*2.5 → -10.00.

### point.py
Попадание точки в прямоугольник 0 ≤ x ≤ 5, 0 ≤ y ≤ 3 (граница включена).

Проверки:
- внутри: (2,1);
- на границе: углы (0,0),(5,3),(0,3),(5,0) и стороны (0,1),(5,2),(2,0),(2,3);
- снаружи: (0,-0.1),(5.1,1),(-0.1,2),(2,3.1),(6,4),(-1,-1);
- углы снаружи: (-0.1,-0.1),(5.1,3.1).

### variant.py (Результат теста)
Категория по числу 0–100; выход за диапазон → «Ошибка диапазона».

Проверки:
- границы интервалов: 0,49 → «Нужна доработка»; 50,84 → «Зачёт»;
  85,100 → «Отличный результат»;
- обычные: 25, 67, 92;
- вне диапазона: -1, 101, -100, 1000 → «Ошибка диапазона».
