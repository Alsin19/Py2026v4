## Задание 6

### statistics.py
Статистика чисел из одной строки: количество, сумма, минимум,
максимум, среднее (2 знака). Пустой ввод → только "Нет данных".
min()/max() не вызываются; деления на ноль нет.

Проверки:
- обычный: 3 -1 4 0 2 → 5, 8, -1, 4, 1.60;
- все отрицательные: -5 -3 -8 → 3, -16, -8, -3, -5.33;
- одно число: 7 → 1, 7, 7, 7, 7.00;
- нули: 0 0 0 → 3, 0, 0, 0, 0.00;
- пустой ввод и только пробелы → "Нет данных";
- лишние пробелы: "  1   2  " → 2, 3, 1, 2, 1.50.

### transform.py
Новый список: отрицательные заменены модулями; исходный сохраняется.

Проверки:
- -3 5 -1 0 → [-3,5,-1,0] / [3,5,1,0];
- все отрицательные: -2 -7 → [2,7];
- все неотрицательные: 1 2 3 → без изменений;
- пустой ввод → [] и [];
- нули: 0 0 → [0,0] и [0,0];
- одно число: -5 → [5].

### positions.py
Все индексы максимума в порядке возрастания; для пустого — "Нет данных".
Максимум определяется отдельно, затем обход с enumerate().

Проверки:
- 3 7 2 7 → [1, 3];
- один максимум: 1 5 3 → [1];
- все равны: 4 4 4 → [0,1,2];
- максимум в начале и конце: 9 1 2 9 → [0,3];
- одно число: 7 → [0];
- отрицательные: -5 -1 -1 → [1,2];
- пустой ввод → "Нет данных".

### variant.py (нечётные числа)
Новый список нечётных в исходном порядке; количество, сумма,
отсортированная копия (sorted). Повторы сохраняются.

Контрольный ввод: -8 -3 0 6 6 1 → [-3, 1], 2, -2, [-3, 1].

Дополнительный непустой набор: 5 -2 3 -7 0 1 →
[5, 3, -7, 1], 4, 2, [-7, 1, 3, 5].

Проверки:
- нет нечётных: -8 0 6 → [], 0, 0, [];
- пустой ввод → [], 0, 0, [];
- повторы: 1 1 3 → [1,1,3], 3, 5, [1,1,3];
- только отрицательные нечётные: -1 -5 → [-1,-5], 2, -6, [-5,-1];
- только чётные: 2 4 6 → [], 0, 0, [];
- одно нечётное: 7 → [7], 1, 7, [7].
