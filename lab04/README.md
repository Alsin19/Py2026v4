## Задание 4

### range_numbers.py
Выводит все целые от a до b включительно: по возрастанию при a < b,
по убыванию при a > b, одно число при равенстве; по одному на строке.

Проверки:
- возрастание: 3..7 → 3 4 5 6 7;
- убывание: 7..3 → 7 6 5 4 3;
- равенство: 5,5 → 5;
- граничные: 0..1, -2..2, -3..-1, 1..0;
- убывание отрицательных: -1..-4 → -1 -2 -3 -4.

### statistics.py
Сумма, число положительных и максимум для n чисел (без списка).
Максимум инициализируется первым введённым значением.

Проверки:
- обычный: 3,-1,4,0,2 → сумма 8, положительных 3, максимум 4;
- все отрицательные: -5,-3,-8 → сумма -16, положительных 0, максимум -3;
- все положительные: 1,2,3 → сумма 6, положительных 3, максимум 3;
- граничное n=1: -7 → сумма -7, положительных 0, максимум -7;
- нули: 0,0,0 → сумма 0, положительных 0, максимум 0;
- некорректное n=0 → ошибка.

### positive_input.py
Запрашивает целое, пока не введено положительное; выводит квадрат
и число отклонённых попыток.

Проверки:
- сразу 7 → 49, отклонено 0;
- -3,0,5 → 25, отклонено 2;
- 0,0,1 → 1, отклонено 2;
- граничное 1 → 1, отклонено 0;
- -10,-20,-30,4 → 16, отклонено 3.

### variant.py (нечётные числа)
Считает количество и сумму нечётных среди n чисел одним циклом,
без хранения списка.

Контрольный набор: n=7, -12,-3,0,2,10,15,20 → количество 2, сумма 12.

Проверки:
- n=0 → 0 и 0;
- нет нечётных: -4,0,8 → 0 и 0;
- все нечётные: 1,3,5 → 3 и 9;
- отрицательные нечётные: -1,-5 → 2 и -6;
- нули: 0,0 → 0 и 0 (0 — чётное);
- некорректное n=-1 → ошибка.

Примечание: в Python остаток `%` для отрицательных нечётных даёт 1
(например, -3 % 2 == 1), поэтому проверка `value % 2 != 0` надёжно
отбирает нечётные при любом знаке.
