## Задание 9

### table.py (без input()/print())

- row_sums(matrix) — список сумм строк; [] → [].
- column_sums(matrix) — список сумм столбцов; [] → []; для непустой
  прямоугольной матрицы (≥1 столбец) число столбцов = len(matrix[0]).
- diagonal_pattern(size) — квадрат size×size: 0 на главной диагонали,
  1 выше (row < column), 2 ниже (row > column); size >= 1.
- transform(matrix) — новая матрица той же формы: нечётные заменены
  нулями, остальные сохранены; [] → []; исходная не изменяется.

### main.py
Ввод прямоугольной матрицы с проверкой длины строк (первая строка задаёт
эталон; при несовпадении — сообщение об ошибке). Вывод сумм строк и
столбцов. Затем запрос положительного размера и вывод диагонального узора
построчно. В конце — transform: печать исходной и новой матриц.

### Проверки

row_sums:
- [] → [];
- [[1,2,3]] → [6]; [[1],[2],[3]] → [1,2,3];
- [[-2,0,3],[4,-5,6]] → [1, 5];
- [[0,0],[0,0]] → [0,0]; [[5]] → [5].

column_sums:
- [] → [];
- [[1,2,3]] → [1,2,3]; [[1],[2],[3]] → [6];
- [[-2,0,3],[4,-5,6]] → [2, -5, 9];
- [[5]] → [5]; [[1,1],[1,1],[1,1]] → [3,3].

diagonal_pattern:
- 1 → [[0]];
- 2 → [[0,1],[2,0]];
- 3 → [[0,1,1],[2,0,1],[2,2,0]] (совпадает с примером);
- 4 → [[0,1,1,1],[2,0,1,1],[2,2,0,1],[2,2,2,0]].

transform (нечётные → 0):
- [] → [];
- контроль: [[-2,0,3],[4,-5,6]] → [[-2,0,0],[4,0,6]];
- [[1,3,5]] → [[0,0,0]]; [[2,4,6]] без изменений;
- [[0,-1],[-2,-3]] → [[0,0],[-2,0]]; [[7]] → [[0]].

Отрицательные нечётные корректно заменяются: в Python -5 % 2 == 1,
поэтому value % 2 != 0 надёжно ловит нечётные при любом знаке.

### Почему функции не меняют исходную матрицу
Все функции строят новые строки и новый внешний список и только читают
входную матрицу. Поэтому исходная матрица остаётся прежней; в main.py
исходная и новая таблицы печатаются рядом — видно, что transform не
изменил исходную.
