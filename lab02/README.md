## Задание 2

### time_parts.py
Переводит `total_seconds` в полные часы, минуты и секунды через `//` и `%`
(без библиотек времени). Часы могут быть больше 23.

Проверки:
- обычное: 3671 → 1 ч 1 мин 11 с;
- граничные: 0, 59, 60, 3600;
- часы > 23: 90000 → 25 ч 0 мин 0 с;
- некорректное: отрицательное значение.

### purchase.py
Считает стоимость тетрадей и сдачу.

Проверки:
- обычный пример: 45×3, оплата 200 → стоимость 135, сдача 65;
- граничные: цена 0, количество 0, оплата ровно равна стоимости;
- некорректные: отрицательные значения, недостаточная оплата.

### Ручной прогноз и результат Python

| Выражение | Прогноз | Python | Совпало |
|---|---|---|---|
| 2 + 3 * 4 | 14 | 14 | да |
| (2 + 3) * 4 | 20 | 20 | да |
| 17 // 5 | 3 | 3 | да |
| 17 % 5 | 2 | 2 | да |
| -7 // 2 | -4 | -4 | да |

Пояснения:
- Умножение имеет приоритет над сложением; скобки меняют порядок.
- `//` — целочисленное деление, `%` — остаток.
- В Python `-7 // 2 = -4` (округление вниз, к −∞), а не −3, как в C/Java;
  при этом `-7 % 2 = 1`, и выполняется `-4·2 + 1 = -7`.

### variant.py
Размещает детали по контейнерам.

Проверки:
- обычное: 17 деталей, вместимость 5 → 3 полных, остаток 2, минимум 4;
- граничные: total = 0 (минимум контейнеров = 0); total = capacity; total = 1, capacity = 1;
- особое: total = 6, capacity = 5 → 1 полный, остаток 1, минимум 2;
- некорректные: отрицательный объём, нулевая вместимость.

Формула округления вверх `(total + capacity - 1) // capacity` даёт
минимальное число контейнеров без циклов и условий; при `total = 0`
результат равен `0`.
