### collections_lab.py

#### word_counts(text)
Возвращает словарь «слово → количество»: нижний регистр, разбиение по
пробельным символам, удаление `.,!?;:` с краёв, пропуск пустых результатов.
Пустой текст → `{}`. Отдельная функция `print_counts_sorted` печатает пары
по алфавиту (сортировка ключей словаря).

Проверки:
- обычный: "Привет, мир! Привет." → {"привет": 2, "мир": 1};
- только пунктуация: "..., ;;; !!!" → {} (все слова очищаются в пустые);
- пустая строка и строка из пробелов → {};
- один регистр: "Кот, кот, КОТ." → {"кот": 3};
- внутренняя пунктуация сохраняется: "ко:т" → {"ко:т": 1};
- смешанный регистр и знаки: "Да, нет; да!" → {"да": 2, "нет": 1}.

#### common_topics(first, second) / all_topics(first, second)
Общие/все уникальные темы как отсортированные списки (через множества;
темы уже в нижнем регистре, сравнение точное).

Проверки:
- ["python","sql","git"] и ["sql","git","docker"] →
  common → ["git", "sql"]; all → ["docker","git","python","sql"];
- нет пересечения: ["a"] и ["b"] → common []; all ["a","b"];
- один список пуст: [] и ["x","y"] → common []; all ["x","y"];
- полное совпадение: ["x","y"] и ["x","y"] → common ["x","y"]; all ["x","y"];
- повторы во входе: ["a","a","b"] и ["b"] → common ["b"]; all ["a","b"].

#### Словарь записи и кортеж
Создаётся словарь {"title": ..., "hours": ...}; значение hours изменяется,
добавляется ключ completed=False. Из title и hours создаётся кортеж,
который распаковывается в две переменные.

Почему запись удобно представить словарём:
- у полей есть понятные имена (title, hours, completed) — код читается сам;
- набор полей можно расширять без изменения позиций (в отличие от кортежа);
- поля можно изменять по ключу (hours), добавлять новые (completed) и
  удалять;
- порядок полей не важен при доступе: rec["hours"] не зависит от того,
  на каком месте стоит hours;
- словарь хорошо ложится в список записей — типичная структура
  «список словарей» для табличных данных (см. records).
